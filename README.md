# Portals for Business: CRM demo

A clickable demo of the Portals CRM for 8 kinds of business: service/handyman, cleaning, home watch, home inspector, landscaping, pet grooming, salon and artist/maker.

Each business has three screens: the owner's desk, the crew's phone and what the customer sees.

All names, numbers and prices on these screens are sample data.

Open `index.html` to use it. The notes box on the right saves only in your own browser.
